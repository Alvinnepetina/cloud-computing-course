# Cloud Computing Concepts Reflection

Cloud computing has become part of my daily life because many applications I use rely on cloud technology. Three cloud services I regularly use are Google Drive, Facebook Messenger, and Canva.

Google Drive is Software as a Service (SaaS) because it allows users to store, edit, and share files online without managing servers or software. It uses the Public Cloud deployment model because anyone with a Google account can access the service.

Facebook Messenger is also SaaS because it provides messaging, voice, and video communication through the internet. It operates using the Public Cloud since millions of users access the same online platform.

Canva is another SaaS application that allows users to create graphic designs through a web browser. It also uses the Public Cloud because users can access their projects online from different devices.

Version control is essential in cloud computing because many developers work together on the same project. Git and GitHub make collaboration easier by recording every change, allowing developers to create branches, merge updates, and restore previous versions when necessary. This reduces errors, improves teamwork, and helps manage cloud infrastructure efficiently.

Overall, this activity helped me realize that cloud computing is already part of my everyday life. Learning Git and GitHub will help me become more organized and prepared for future cloud-based projects.
